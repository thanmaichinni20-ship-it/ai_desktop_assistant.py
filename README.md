# AI Desktop Assistant

A voice-activated desktop AI assistant with modern GUI.

## Features
- 🎤 Voice Recognition
- 🔊 Text-to-Speech
- 🌤️ Weather Information
- 🌐 Web Integration (YouTube, Google, Gaana)
- 📱 Clean GUI Interface

## Tech Stack
Python, Tkinter, pyttsx3, SpeechRecognition, Requests

## Installation
pip install -r requirements.txt

## Run
python ai.desktop.py

## Commands
- "Hello" - Greeting
- "What is your name?" - Introduction
- "Time now" - Current time
- "Weather" - Weather info
- "YouTube/Google/Play music" - Open websites
- "Shutdown" - Exit app
